# 腾讯财经五档盘口插件

## 设计与边界

基于 `48f5d6e5`，按已批准方案实现独立 `depth5` Provider（L2 插件扩展）。
不改变其他数据源、偏好、服务、前端和已有用户数据。不自动启用，不提供历史盘口。
HTTP 客户端使用现有 httpx，沪深股票与 ETF 显式按交易所后缀映射。
原始盘口量为手，时间按北京时间转毫秒 epoch；缺失不补零，异常及过期快照拒收。

## 实施计划

1. 先补合成样本解析、单位、时间、异常和插件集成测试，确认未实现时失败。
2. 新增 plugin.yaml、client.py、provider.py；复用现有五档路由和缓存。
3. 核对能力矩阵、试拉接口、共享盘口服务；更新说明。
4. 执行定向回归、Ruff、只读实测及 diff 检查，交用户审核，不提交或切换配置。

## 限速设计说明

当前通用盘口服务只读取能力快照中的限制，不读取插件 config 的 batch/rpm。
因此插件自行拆成最多 50 只的一批，腾讯 HTTP 请求在进程内共享至少 3 秒间隔。
这不是腾讯官方配额；不能将多个进程的独立预算当成账户或 IP 级统一限速。

HTTP 403/429 后至少冷却 60 秒；数字形式的 `Retry-After` 更长时遵从该值。
不自动重试、不换代理、不跨源回退。其他网络错误按批次隔离。
创建插件和启动检测不联网；只有试拉或显式选择后的盘口调用才请求腾讯。

## 部署与启用（审核通过后由用户操作）

1. 本地部署更新代码并重启后端；Docker 需重建并更新镜像。
2. 检查“设置 → 数据源”出现“腾讯财经(五档盘口)”卡片。可用状态仅表示本地依赖就绪，
   不代表当前上游网络正常。无需 API Key，无需安装 easyquotation 或 Node.js。
3. 先调用现有只读试拉接口。当前插件卡片没有专用试拉按钮；不能使用通用 YAML
   编辑器测试腾讯文本响应。将下面地址中的端口替换为实际后端端口；如配置了访问认证，
   请使用已有认证方式。

   ```bash
   curl -X POST http://127.0.0.1:3018/api/settings/data-sources/test \
     -H 'Content-Type: application/json' \
     -d '{"provider":"tencent","dataset":"depth5","symbols":["600519.SH","000001.SZ","510300.SH","159915.SZ"]}'
   ```

   正常应返回 `rows: 4`、价量数组和毫秒 `timestamp`。全量失败时有 `error`，
   部分缺失看 `missing_symbols`，不能只检查 HTTP 状态码。
4. 在能力路由中**只把五档盘口切到腾讯**，日K、实时、分钟、财务保持不变。
   等效配置接口如下（会更改偏好，本次开发不会执行）：

   ```http
   PUT /api/settings/preferences/data-providers
   Content-Type: application/json

   {"depth5_data_provider":"tencent"}
   ```

5. 确保日K/enriched 已同步到对应交易日，先以 30～60 秒刷新间隔小范围观察连板盘口。
   插件仅取数；现有封板名单仍来自既有 enriched 数据。它不会新增 ETF 五档页面，也不会
   全市场采集/存储每个五档快照。
6. 回滚时只切回原五档来源；原来源也不可用时关闭相关监控，不伪装成已有替代数据。

## 数据质量与限制

- 首版接受沪市 `60/68/5`、深市 `00/30/15` 开头的标准后缀代码；覆盖以实际可返回数据
  的股票/ETF为准，不承诺这些号段内所有产品。指数、北交所、港美股不开放。
- 请求代码必须由 `.SH/.SZ` 映射；不能用代码首位推测市场（ETF `510300.SH` 是沪市）。
- 价格和数量从一档到五档排列；数量直接保留腾讯原始“手”，不乘100。封单额由现有前端
  按“手 × 100 × 价格”计算。价格保留原精度，不固定四舍五入到两位。
- 缺失、非有限数、负数、价格与数量零值不一致、双方全空、当日无成交均拒收，不补零。
  当日无成交过滤是保守措施，也会排除尚无成交的有效证券，不能据此单独判断停牌。
- 只接受**北京时间当天、工作日**的数据；不依赖服务器本地时区。超过有效时间参考点
  180 秒或超前系统时间 5 秒以上的快照拒收。午休参考点固定11:30，收盘后固定15:00。
  当天收盘快照可试拉；跨日/周末不回放上一交易日数据。开盘刚开始若尚无新快照可能为空。
- 节假日不是专门维护的日历，依赖“当日时间戳”拒收上一交易日快照。拒收结果不会伪装
  成最新时间。系统时钟应正确同步。
- 插件不保存自己的行情缓存。通用盘口服务全量失败时仍保留此前缓存，缓存年龄继续增长；
  部分成功时按现有逻辑替换当轮缓存。本次不改变该行为，不能把旧缓存视为新盘口。
- 网页行情不是授权商业行情 API；无长期可用性、延迟、全覆盖或商用授权承诺。数据源
  和字段结构可能变化。插件不绕过访问限制，不应作为自动交易唯一依据。
